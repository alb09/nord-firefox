Nord Auto

The Nord palette, both halves. Follows Firefox's Light / Dark / System setting.

A fork of dragonejt's Nord theme, which ships dark only. The dark palette is upstream's, untouched; this adds the light one.

Install

This add-on is signed but unlisted on addons.mozilla.org, so it will not appear in Firefox's add-on search. Install it once from the signed file:

  • Download nord-auto-1.xpi, signed by AMO, 8105 bytes
  • Open about:addons, then the gear menu → Install Add-on From File

That is a one-time step. Firefox then polls the update manifest below on its own schedule and applies new versions without you doing anything.

Palette

Thirty-six colour keys per palette, all from the official Nord palette. Each side declares its own color_scheme, so menus and built-in pages follow the active variant.

  • Light, Snow Storm: #d8dee9, Frost #eceff4
  • Dark, Polar Night: #2e3440, the base
